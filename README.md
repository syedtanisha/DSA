## 🧠 Problem-Solving Approach

For every problem, I try to follow these steps:

1. Understand the problem
2. Identify the pattern
3. Think of a brute-force solution
4. Find a better/optimized approach
5. Write the code
6. Test with different cases
7. Analyze **Time Complexity**
8. Analyze **Space Complexity**
